### 9. UIコンポーネント（shadcn/ui）

**`theme-provider.tsx`** — `next-themes`のラッパー。8行だけ。`"use client"`で Client Component 化している理由は、`next-themes`がブラウザの`localStorage`を使うから。

**`button.tsx`** — `class-variance-authority`(cva)パターン：
```typescript
const buttonVariants = cva("ベースクラス", {
  variants: {
    variant: { default: "...", outline: "...", ghost: "..." },
    size: { default: "...", sm: "...", lg: "..." },
```

## Web側全体のアーキテクチャまとめ

```
ブラウザ
├── /image-chat  (page.tsx) ← チャットUI
│   └── useChat → POST /api/image-chat → KB検索 + Claude Sonnet ストリーミング
│
├── /images  (page.tsx) ← アップロード＋検索UI
│   ├── POST /api/image-upload → presigned URL取得
│   │   └── PUT presigned URL → S3直接アップロード
│   └── POST /api/image-search → KB検索のみ（LLMなし）
│
├── lib/aws.ts ← AWS認証共通
├── lib/utils.ts ← cn()関数
└── components/ui/* ← shadcn/uiコンポーネント
```

**データフローの全体像：**
```
1. アップロード: ブラウザ → presigned URL → S3 (raw-images/)
2. OCR処理:     S3イベント → Lambda → Claude Vision → S3 (datasource/)
3. KB同期:      S3イベント → Lambda → Bedrock KB → Pinecone
4. 検索:        ブラウザ → Next.js API → Bedrock KB (HYBRID+reranking) → レスポンス
5. チャット:    ブラウザ → Next.js API → KB検索 + Claude Sonnet → SSEストリーミング
```
